# Keyboard Shortcuts

Photoshop-style shortcuts for ID Stack. Only implemented features have
shortcuts — new ones are added as features land.

## Tools

| Action | Windows | macOS |
|---|---|---|
| Move / Select tool | `V` | `V` |
| Type tool | `T` | `T` |
| Shape tool | `U` | `U` |
| Hand (pan) tool | `H` | `H` |

## Canvas navigation

| Action | Windows | macOS |
|---|---|---|
| Temporary Hand tool | Hold `Spacebar` | Hold `Space` |
| Pan canvas | `Spacebar` + Left-click + Drag | `Space` + Click + Drag |
| Pan canvas | Middle-click + Drag | Middle-click + Drag |
| Zoom in | `Ctrl` + `+` | `Cmd` + `+` |
| Zoom out | `Ctrl` + `-` | `Cmd` + `-` |
| Zoom 100% (actual pixels) | `Ctrl` + `1` | `Cmd` + `1` |
| Reset zoom | `Ctrl` + `0` | `Cmd` + `0` |
| Mouse wheel zoom | `Ctrl` + Scroll | `Cmd` + Scroll |

*Planned (not yet active):* temporary zoom `Ctrl+Space`, cycle screen modes `F`,
rulers `Ctrl+R`, guides `Ctrl+;`, grid `Ctrl+'`, snap `Ctrl+Shift+;` — these
arrive with the rulers/guides features.

## File

| Action | Windows | macOS |
|---|---|---|
| Save template | `Ctrl` + `S` | `Cmd` + `S` |

*Planned:* new document `Ctrl+N`, open `Ctrl+O`, save as `Ctrl+Shift+S`,
print `Ctrl+P` — arrive with the template library and print features.

## History

| Action | Windows | macOS |
|---|---|---|
| Undo | `Ctrl` + `Z` | `Cmd` + `Z` |
| Redo | `Ctrl` + `Y` or `Ctrl` + `Shift` + `Z` | `Cmd` + `Y` / `Cmd` + `Shift` + `Z` |

## Selection

| Action | Windows | macOS |
|---|---|---|
| Select all objects | `Ctrl` + `A` | `Cmd` + `A` |
| Deselect | `Ctrl` + `D` or `Esc` | `Cmd` + `D` / `Esc` |
| Delete selected | `Delete` / `Backspace` | `Delete` / `Backspace` |

*Planned:* inverse selection `Ctrl+Shift+I`, select all layers
`Ctrl+Alt+A` — arrive with grouping/advanced selection.

## Layers

| Action | Windows | macOS |
|---|---|---|
| Bring layer forward | `Ctrl` + `]` | `Cmd` + `]` |
| Bring layer to front | `Ctrl` + `Shift` + `]` | `Cmd` + `Shift` + `]` |
| Send layer backward | `Ctrl` + `[` | `Cmd` + `[` |
| Send layer to back | `Ctrl` + `Shift` + `[` | `Cmd` + `Shift` + `[` |
| Reorder layer | Drag in Layers panel | Drag in Layers panel |

*Planned:* group `Ctrl+G`, ungroup `Ctrl+Shift+G`, merge `Ctrl+E`,
duplicate layer `Ctrl+J`, new layer `Ctrl+Shift+N`, hide layer `Ctrl+,`,
free transform `Ctrl+T` — arrive with grouping/transform features.

## Object movement

| Action | Windows | macOS |
|---|---|---|
| Move selected 1 px | Arrow keys | Arrow keys |
| Move selected 10 px | `Shift` + Arrow keys | `Shift` + Arrow keys |

## Text editing (inside text inputs)

Standard browser text editing applies. Bold/italic/underline shortcuts
(`Ctrl+B/I/U`) will be added when rich text styling lands in the canvas.
